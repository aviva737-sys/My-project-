# Монтаж Reels: проект

Монтаж собирается из исходника двумя скриптами. Ручных шагов в редакторе нет, поэтому любую правку можно внести в код и пересобрать ролик.

| Файл | Что внутри |
|---|---|
| `words_raw.txt` | Расшифровка речи по словам. Тайминги взяты из исходных субтитров автора, орфография исправлена («наверное» вместо «на верное») |
| `refine_words.py` | Уточняет начало каждого слова с точностью до кадра → `words.json` |
| `render.py` | Картинка. Виртуальная камера (следит за спикером, плавные наезды, акцентные зумы, тряска, вспышка на склейке), цветокоррекция, виньетка, кинетические субтитры, анимированная инфографика и иконки |
| `audio.py` | Звук. Шумоподавление и эквализация голоса, компрессия, громкость −14 LUFS, синтезированные звуковые эффекты, тихая lo-fi подложка с приглушением под речь |
| `captions.srt` / `captions_words.json` | Слой субтитров (фразы и тайминги по словам) для CapCut / Premiere / DaVinci |
| `cues.json` | Тайминги звуковых эффектов |

## Как убраны старые субтитры
Вшитые субтитры автора находятся в полосе y ≈ 950–1065 исходного кадра 720×1280. Виртуальная камера никогда не берёт строки ниже y = 925 (`SAFE_BOTTOM`), поэтому старые надписи физически не попадают в кадр. Под ними нет размытия и масок. Во вступлении (ч/б хук) кадр взят внутри рамки «видоискателя»: остались фокус-скобки, а вместо обрезанной надписи добавлена своя мигающая метка REC.

## Пересборка
```bash
python3 render.py events cues.json            # звуковые метки и субтитры
python3 render.py full  SRC.mp4 video.mp4     # картинка (можно кусками: ... f0 f1)
python3 audio.py SRC.mp4 cues.json out/       # стемы + микс
ffmpeg -i video.mp4 -i out/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -movflags +faststart final.mp4
```
Режимы `render.py overlay` (только графика и субтитры, ProRes 4444 с альфа-каналом) и `render.py base` (только перекадрированное видео с цветокоррекцией) нужны для доработки в любом монтажном редакторе.
